4. CONSISTENCY CORRECTIONS FOUND DURING REVIEW
--------------------------------------------------------------------------------
- .env.example previously told the operator to chmod the authorized public key
  0600. The entrypoint stages keys as root:root 0644 because sshd's
  privilege-separated child must read them without DAC_OVERRIDE. The template
  comment now says 0644, matching README, AGENT_GUIDE and MANUAL_PREREQS.
- README.md still labelled Stage 3 as live deployment. The roadmap now treats
  Stage 3 as documentation, Stage 4 as live deployment, and later stages as
  proxy/packaging/teardown.
- MANUAL_PREREQS.md now lists BASTION_ADMIN_PUBLIC_KEY_PATH alongside the
  informational BASTION_ADMIN_PUBLIC_KEY placeholder.
